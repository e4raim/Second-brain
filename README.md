# Библиотека знаний компании

Единая база знаний для обучения и работы: от первого дня стажёра до управления отделом.

**Есть вопрос? Начни с [FAQ.md](FAQ.md)** — там вопросы со ссылками на ответы.

**Сайт для стажёров и агентов:** https://claude.ai/artifact/EHiiDEK64x9FC7hoqBWvne (собирается командой `python3 site/build.py`).

## Как устроена библиотека

```
inbox/        ← сюда загружаются сырые материалы (как есть)
  notes/        заметки автора
  company/      обучение компании: регламенты, презентации, записи тренингов
  external/     книги, курсы, видео не из компании
  scripts/      скрипты разговоров
  dialogs/      записи и расшифровки реальных диалогов
sources/      ← конспект каждого материала (1 источник = 1 файл)
knowledge/    ← база знаний по темам: выжимка из всех источников
  01-company/          компания, ценности, стандарты, регламенты
  02-product/          продукт / услуги, чем мы отличаемся
  03-sales/            процесс продаж по этапам
  04-objections/       возражения и ответы на них
  05-scripts/          рабочие скрипты (вычищенные версии)
  06-dialog-reviews/   разборы реальных диалогов: что сработало, что нет
  07-management/       управление: найм, адаптация, планёрки, метрики, мотивация
  08-self-management/  личная эффективность, режим, мышление
materials/    ← готовые PDF для выдачи (исходники в materials/src)
tracks/       ← маршруты чтения по ролям (что читать и в каком порядке)
templates/    ← шаблоны для всех типов заметок
```

## Путь материала

1. **Загрузка** — файл, текст, расшифровка или ссылка попадает в `inbox/`.
2. **Конспект** — по нему создаётся карточка в `sources/` (суть, ключевые идеи, цитаты, для кого).
3. **Разнесение** — идеи раскладываются по темам в `knowledge/`; если тема уже есть, она дополняется, а не дублируется. Противоречия между источниками помечаются явно.
4. **Маршруты** — новые темы добавляются в нужные треки ролей в `tracks/`.
5. **FAQ** — вопросы, на которые отвечает тема, добавляются в `FAQ.md`.

## Роли и уровни

| Роль | Кто это | Трек |
|---|---|---|
| Стажёр | первые недели, базовые понятия и первые звонки | [tracks/intern.md](tracks/intern.md) |
| Агент | самостоятельная работа с клиентами | [tracks/agent.md](tracks/agent.md) |
| РОП | руководитель отдела продаж | [tracks/sales-head.md](tracks/sales-head.md) |
| Руководитель | управление компанией / направлением | [tracks/executive.md](tracks/executive.md) |

Каждая заметка помечена ролями (`roles`) и уровнем (`level`: базовый / рабочий / продвинутый), поэтому одна и та же тема может читаться стажёром на базовом уровне, а РОПом — с управленческой стороны.
