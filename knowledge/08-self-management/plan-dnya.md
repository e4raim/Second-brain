# План дня и как разгрести завалы

**Отвечает на вопросы:**
- Как спланировать рабочий день агента?
- У меня 150+ просроченных звонков. С чего начать?
- Как не распыляться в течение дня?

**Коротко:** быстрые задачи закрываешь в начале дня, запланированные звонки ставишь первым большим блоком, просрочку разбиваешь на партии по 40–50 и бьёшь блоками. Объекты не ищешь отдельно, они появляются из основного потока звонков. Задачи на завтра ставишь с вечера.

## Пример плана дня (10:00–20:00, когда накопились завалы)
| Время | Блок |
|---|---|
| 10:00–10:15 | Быстрая задача (например, снизить цену по двум объектам), чтобы не тащить её весь день |
| 10:15–11:45 | Запланированные звонки (50) — твёрдые обязательства, пока голова свежая |
| 11:45–13:15 | Просрочка, блок 1 (~50) |
| 13:15–14:15 | Обед |
| 14:15–15:30 | Вычисления, блок 1 (~40) |
| 15:30–17:00 | Просрочка, блок 2 (~50) |
| 17:00–17:15 | Пауза |
| 17:15–18:30 | Вычисления, блок 2 (~40) |
| 18:30–19:30 | Просрочка, блок 3 |
| 19:30–20:00 | Итог дня: выписать перспективные контакты под новые объекты, перенести остаток |

## Правила
- **Вычисления — топливо для звонков.** Без них нет новых лидов, не откладывай их «на потом».
- **Просрочка горит:** каждый день протухания снижает конверсию. Но за один день 168 звонков не закрыть, нужно два.
- **Одно дело за раз.** Агент одновременно пишет одному, звонит другому, болтает с третьим, а потом удивляется, что ничего не сделано.
- Задачи и отчёт ставить с вечера. Работать в одно и то же время. Не залипать в соцсетях.
- Каждое утро — отработка диалогов. Наставник делает это каждое утро уже два года.
